# 연구 제안서 — 김소연 교수님 검토용

작성자: 김준 / 작성일: 2026-09-29 / 상태: 제출용 문안 확정, 미발송·승인 대기

**제목: 저비트 추론 모델의 출력 길이 증가에서 확률 왜곡과 샘플링 후보 집합 변화의 역할 분리**

양자화는 모델의 저장·연산 비용을 줄이지만, 추론 모델에서는 생성 토큰이 늘어 효율 이득을 줄일 수 있습니다. Lotfi 등은 길이 증가와 분기 표지 토큰 억제를, ReSET은 단계별 온도 조정을 연구했습니다. Lian 등은 greedy에서도 길이 증가를 보고했습니다. 따라서 현상 자체나 단순 샘플러 조정을 새 기여로 삼지는 않습니다.

남은 질문은 양자화 확률을 사용하는 상태에서 원본 모델의 top-p 후보 집합을 제공하면 초과 토큰이 얼마나 복구되는가입니다. 후보 선택과 점수의 분리에는 선행연구가 있지만, 확인한 근접 자료에서는 양자화 전후의 두 공급자를 교차해 자유 생성의 길이·정답률·상호작용을 함께 검증한 결과를 찾지 못했습니다.

BF16 원본 F와 GPTQ W3/g128 모델 Q의 확률·후보 집합을 조합한 FF·QQ·QF·FQ를 비교합니다. 각 조건의 현재 토큰열을 두 모델이 동일하게 처리합니다. 주 대상은 DeepSeek-R1-Distill-Qwen-1.5B, GSM8K, 온도 0.6, top-p 0.95입니다. 양자화 가중치는 BF16 연산으로 실행하며 실제 저비트 커널의 속도 향상은 주장하지 않습니다.

H1은 QF가 QQ의 초과 평균 소비 토큰을 50% 넘게 복구하면서 QQ 대비 정답률 손실을 3%p 미만으로 유지한다는 것입니다. 추론과 최종 답변을 포함한 토큰 수를 고정 예산에서 평가하고, 문제 단위 신뢰구간으로 두 조건을 모두 검정합니다. 분모가 불안정하면 절대 차이만 보고합니다. 후보 수 변화·종료 토큰 복원이라는 경쟁 설명도 추가 대조로 구분합니다.

기여는 특정 생성 정책의 개입 효과와 한계의 정량화입니다. 정밀하게 20% 복구를 배제할 경우에도 이 정책의 효과 상한을 제시할 수 있으나, 넓은 구간이나 원 현상 미재현을 기여 확보로 보지 않습니다. 50%·20%·3%p는 문헌의 예측값이 아닌 검토 요청 기준입니다.

승인 후 1.5B 구현과 별도 파일럿으로 원 현상·처리량·정밀도를 확인하겠습니다. 관문 통과 시 10/12 핵심 결과, 11/20 주요 검증, 12/14 논문·최종심사를 목표로 하며, 승인이나 계산 일정이 늦어지면 범위를 재평가하겠습니다. 위 연구 방향과 효과 기준의 타당성을 검토 부탁드립니다.

참고문헌: [Lotfi et al.](https://arxiv.org/abs/2606.00206), [ReSET](https://arxiv.org/abs/2606.13233), [Lian et al.](https://arxiv.org/abs/2606.25519), [Contrastive Decoding](https://aclanthology.org/2023.acl-long.687/), [Min-k](https://arxiv.org/abs/2604.11012).

## 승인 시 확인할 사항

1. 특정 조건의 정책 개입 효과·정밀한 효과 상한을 학위논문의 중심 기여로 삼는 방향에 동의하시는지.
2. 복구 50%, 작은 효과 상한 20%, 정확도 손실 3%p의 기준을 유지할지.
3. 10/12 발표에 요구되는 확증 수준과, 승인 지연·정밀도 부족 시 허용할 범위 조정.
