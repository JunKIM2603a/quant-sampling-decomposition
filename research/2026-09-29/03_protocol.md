# 확률과 후보 집합 교환 실험 — 제안 프로토콜 v0.1

상태: DRAFT / 지도교수 승인 전 / 실험 미실행. 이 문서는 공개 사전등록 완료를 뜻하지 않는다. 최종 모델 revision, 구현 버전, split 해시, 시드 수, 검정력 계획은 확증 평가 전에 기록하고 동결한다.

## 1. 문제와 범위

원 모델 F와 그 가중치만 양자화한 모델 Q를 비교한다. 양자화는 다음 토큰의 확률값과 top-p 후보 집합을 함께 바꾼다. 두 요소를 따로 교환해, 생성 토큰 증가에 대한 조작 가능한 경로를 측정한다.

이 실험은 특정 디코딩 정책의 개입 효과를 식별한다. 모든 양자화 손상의 자연적 매개효과나 유일한 원인 비율을 증명하지 않는다. 가중치의 변화가 두 요소를 함께 발생시키므로 상호작용을 반드시 보고한다.

Calibration corpus는 인용 논문의 정확한 재현 설정과 다를 수 있다. 이를 숨기지 말고 자체 통제 설정으로 기록한다. 정확한 재현 arm은 필요 시 별도 이름으로 둔다. GPTQ와 AWQ를 비교할 때는 calibration 자료를 일치시켜 방법 효과와 데이터 효과를 혼동하지 않는다.

## 3. 생성 정책

현재 prefix를 h, T로 softmax한 원본·양자화 분포를 각각 p_F(v|h), p_Q(v|h)라 한다. M_F(h), M_Q(h)는 각 분포에서 top-p=0.95에 도달하는 최소 후보 집합이다. 경계 토큰 포함 규칙과 동률 처리(token ID 순)를 모든 arm에서 통일한다.

두 공급자 a,b ∈ {F,Q}에 대해 다음을 구현한다.

`q_ab(v | h) = p_a(v | h) * I[v in M_b(h)] / sum_{u in M_b(h)} p_a(u | h)`

| arm | a: 확률 공급자 | b: mask 공급자 |
|---|---|---|
| FF | F | F |
| QQ | Q | Q |
| QF | Q | F |
| FQ | F | Q |

각 arm은 자신이 생성한 prefix를 갖는다. 해당 arm 안에서는 F와 Q가 **같은 prefix**를 처리한다. 두 모델의 KV cache도 각각 그 prefix로 업데이트한다. 다른 arm의 토큰열에서 계산한 mask를 재사용하지 않는다.

Softmax, 누적 합, 재정규화는 FP32로 계산하고 원래 model logits의 dtype을 기록한다. hybrid arm에는 top-p를 다시 한 번 적용하지 않는다. 특수 토큰과 `</think>`에 관한 모델 고유 정책을 보존하며, 일반 EOS만 보고 reasoning이 끝났다고 처리하지 않는다.

## 4. H1과 추정량

L_ab = 해당 arm의 평균 소비 생성 토큰 수, A_ab = 정답률.

`Delta = L_QQ - L_FF`

`R = (L_QQ - L_QF) / Delta`

R은 **QF 개입을 통한 초과 토큰 복구율**이다. 0~1로 자르지 않는다. 상호작용 때문에 음수 또는 1 초과가 가능하다. 이를 “전체 원인의 R%가 샘플러다”로 해석하지 않는다.

**주가설 H1**: 주 조건에서 R > 0.50이며 A_QF - A_QQ > -0.03이다. 개념 설명에서는 “50% 이상 복구”로 표현하되 검정은 경계값을 기준으로 한다.

H1 지지는 R의 단측 95% 하한 >0.50, 정확도 차이의 단측 95% 하한 >-0.03을 **둘 다** 요구한다. 두 조건을 모두 만족해야 하는 intersection-union 판정이므로 각각 유의수준 0.05를 사용한다. 효과 추정에는 양측 95% 구간도 함께 낸다.

**유용한 부정 결과**: R의 단측 95% 상한 <0.20이면 해당 개입은 20% 수준의 복구를 제공하지 못한다. R이 명확히 음수면 단순 무효과가 아닌 악화로 보고한다. 차이가 작다는 동등성 주장은 별도로 90% 구간이 [-0.20,0.20] 안에 드는지 판단한다. 이 두 판단을 혼용하지 않는다.

20%와 50% 사이의 결과는 중간 효과이며, H1 미지지라고 해서 무의미한 결과로 버리지 않는다. 신뢰구간이 양쪽을 모두 덮으면 판단 불가다. 기준값은 실질적 의사결정을 위한 제안값이며 파일럿의 효과 방향을 보고 유리하게 수정하지 않는다.

## 5. 2×2 전체 결과와 상호작용

경로 선택에 따라 해석이 바뀌는지 확인한다.

`Mask_F = L_FQ - L_FF`

`Mask_Q = L_QQ - L_QF`

`Interaction = L_QQ - L_QF - L_FQ + L_FF`

기술 통계로 다음 대칭 분해도 함께 제시할 수 있다.

`C_mask = ((L_FQ-L_FF) + (L_QQ-L_QF)) / 2`

`C_prob = ((L_QF-L_FF) + (L_QQ-L_FQ)) / 2`

`C_mask + C_prob = Delta`

이 분해는 두 경로를 평균하는 약속이지 고유한 인과 분율이 아니다. 주가설 R과 혼용하거나 결과를 보고 더 유리한 분해로 교체하지 않는다.

## 6. 1차 관문과 중단 기준

아래 수치는 **실행 여부를 결정하기 위한 제안 관문**이다. 지도교수와 확정할 때 변경 이력을 남긴다.

1. 형식 오류·정답 추출 오류·토크나이저 불일치를 먼저 제거한다. FF 원본 성능이 현저히 낮으면 연구 결과로 해석하지 않는다.
2. 파일럿에서 FF 정답률 50% 이상, QQ 정답률 25% 이상을 요구한다. 이는 범용 능력 척도가 아니라 완전 붕괴를 피하기 위한 기준이다.
3. 파일럿의 L_QQ/L_FF ≥1.20이고, paired bootstrap에서 Delta>0의 방향이 확인돼야 복구율 연구로 진행한다. 파일럿은 탐색 결과로만 표시한다.
4. FF와 QQ의 cap 도달률이 각각 20% 미만이어야 잠재적인 길이 변화 해석이 비교적 가능하다. 초과하면 고정 예산의 소비량·미완료율 연구로 범위를 바꾸거나 중단한다. 결과를 보고 cap을 계속 늘리지 않는다.
5. 전체 확증의 예상 비용이 10/10까지 끝낼 수 있는 실제 가용 GPU 시간 안에 들어야 한다. 1,319문제로도 20% 상한/3%p 비열등성을 판단하기 어려우면 부정 결과의 완결 가능성을 낮게 평가한다.
6. 주요 문헌 재검색에서 같은 2×2 원인 분해가 발견되면 차별점 없이 진행하지 않는다.

GPTQ-W3에서 원 현상이 없으면, 사전 지정한 AWQ-W3를 **별도 파일럿**으로 1회만 점검할 수 있다. 이에 따라 주 조건을 바꾸면 확인 데이터 개봉 전에 protocol v0.2로 명시한다. test 결과를 보고 방법·비트·prompt를 바꾸어 유리한 설정을 찾지 않는다.

## 7. 필요한 대조군

| 대조/검사 | 목적 | 해석 |
|---|---|---|
| F와 Q를 동일 가중치로 둔 4-arm 검사 | 교환 구현의 무효과 확인 | 분포와 생성 규칙이 일치해야 함 |
| top-p=1, top-k 비활성 | mask 교환이 없어지는 경계 조건 | FF=FQ, QQ=QF의 분포가 같아야 함 |
| 동일 모델/동일 설정 재실행 | GPU 수치 비결정성과 샘플링 변동 점검 | 시드가 같다고 자동으로 완전 결정을 가정하지 않음 |
| greedy 원본 vs 양자화 | 문헌의 별도 경로 확인 | stochastic H1을 이 결과로 대체하지 않음 |
| T 고정 후 top-p 0.90/0.99/1.00 | 주 조건 주변의 민감도 | 최적 top-p 탐색으로 논문을 바꾸지 않음 |
| 실제 종료 토큰 포함 여부 기록 | mask가 종료 가능성을 지웠는지 확인 | 가지치기와 조기종료 경로를 구분할 단서 |
| 종료 토큰을 양쪽 mask에 보존하는 추가 arm | 종료 토큰 탈락만으로 효과가 설명되는지 점검 | 주검정 이후 고정된 보조 분석 |

## 8. 지표와 통계

- 기본 집계 단위는 **문제**다. 여러 seed의 결과를 문제 안에서 평균한 뒤 문제 단위 paired bootstrap 10,000회로 arm 간 차이를 추정한다. seed 변동은 별도 표로 공개한다. 토큰을 독립 표본처럼 세지 않는다.
- R의 분모 Delta에 대한 신뢰구간도 제시한다. Delta의 구간이 0을 포함하거나 bootstrap 분모의 부호가 불안정하면 비율 CI를 억지로 계산하지 않고 원 단위 차이와 불확실성만 보고한다.
- 주 데이터 전체에 대한 소비 토큰 평균을 사용한다. 정답을 맞힌 문제만 골라 길이를 비교하는 것은 처치 후 선택 편향이 있어 주 분석으로 쓰지 않는다.
- 정답률은 최종 답의 결정적 parser로 계산한다. GSM8K의 최종 수치·부호·소수·분수 표기를 처리하고, 미완료/추출 실패를 별도 분류하면서 기본 점수에서는 오답 처리한다.
- “중간에 정답 숫자가 등장했다”는 문자열 검사로 overthinking 오류를 정의하지 않는다. 그 분석이 필요하면 명시적인 중간 답과 최종 답을 사람이 확인한 별도 표본으로 수행하며 주 endpoint로 쓰지 않는다.
- cap에 도달한 길이는 완성된 추론 길이가 아니다. 주지표는 cap 아래 **실제 소비된 토큰 수**이며, cap 도달률·최종 답 미완료율을 함께 보고한다.
- mask 크기, mask 간 Jaccard, 확률 가중 symmetric difference, 종료 토큰 탈락률은 원인 진단용 보조 지표다. raw softmax KL과 sampling 후 JS/TV를 구별한다. 서로 다른 mask의 0 확률 때문에 KL이 무한대가 되는 것을 임의 smoothing으로 숨기지 않는다.
- 확증 시점은 사전 동결한 표본·시드가 완료된 뒤 1회다. 중간 결과는 기술 통계로만 표시하고, 유의해질 때까지 추가 seed를 돌리지 않는다.
- 추가 모델·양자화·top-p 셀의 지지 개수를 결론으로 쓸 때는 사전 고정한 family에 Holm 보정을 적용한다. 탐색 subgroup은 별도 표시한다.

## 9. 표본수와 정밀도

파일럿의 문제별 차이·공분산을 사용해 1,319문제에서 예상되는 구간 폭을 계산한다. 같은 문제의 seed만 늘리는 것은 새로운 독립 문제를 확보하는 것과 다르다. 파일럿 기반 추정치는 불안정하므로 보수적인 분산 가정도 함께 평가한다.

독립 문제가 1,319개이고 정답 불일치율이 약 0.2라는 단순 가정에서, paired 정확도 차이의 표준오차는 대략 sqrt(0.2/1319)=1.23%p다. 이는 설계 감각용 근사이며 실제 불일치율·다중 seed 집계·길이 분포에 대한 검정력 증명이 아니다. 주 복구율 R의 정밀도는 파일럿 없이는 알 수 없다.

## 10. 재현과 일반화

1차 결과 뒤 동일 1.5B에서 MATH-500, 다른 양자화(AWQ-W3/GPTQ-W4)를 고정해 확인한다. GPTQ-W4에 원래 토큰 증가가 거의 없으면 R을 비교하지 않고 절대 차이만 보고한다. 추가 모델은 DeepSeek-R1-Distill-Qwen-7B를 우선한다. 같은 계열의 크기 변경은 완전히 독립적인 모델 가족 재현이 아님을 표시한다.

가능하면 Qwen3-4B 등 다른 추론 학습 계열을 1개 추가하되, 모델 카드·메모리·chat template 검증 후 별도 protocol로 고정한다. 4090 두 장이 자동으로 48GB 단일 GPU처럼 작동한다고 가정하지 않는다.

## 11. 데이터·산출물

각 실행은 모델 revision, 양자화 방법/코드 commit, calibration ID 해시, tokenizer hash, prompt/template, generation config, seed, parser version, elapsed time, peak VRAM을 저장한다. 문제별로 arm, output token IDs, stop reason, final-answer parse, score를 기록한다. 전체 vocab logits를 모든 토큰에 저장하지 말고 online 요약과 감사용 일부 checkpoint를 저장한다.

시험자료는 공개 수학 데이터만 사용한다. test는 calibration, prompt 조정, decoder 선택에 사용하지 않는다. 사전학습 오염을 완전히 배제했다고 주장하지 않으며, 최종 일반화 주장에는 별도 문제 집합 재현이 필요하다.

원시 모델 가중치·대용량 추론 로그·외부 논문 본문을 이 Git 저장소에 올리지 않는다. 재현 설정, 문제별 요약, 해시, 분석 코드 및 허용된 범위의 결과를 저장한다.
