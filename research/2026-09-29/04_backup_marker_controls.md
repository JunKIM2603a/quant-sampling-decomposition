# 예비 후보: 과잉추론 단어 억제의 효과는 의미 때문인가, 개입량 때문인가

상태: 조건부 예비 후보. 주 후보와 동시에 본실험을 진행하지 않는다. 현재 모델 실험·대조군 매칭은 수행하지 않았다.

## 문제 정의

Lotfi et al.은 분기·망설임을 나타내는 단어를 억제하는 방법과 무작위 단어 억제를 비교한다. 원문의 무작위 목록에는 수학 풀이에 드물게 등장할 것으로 보이는 어휘가 포함돼 있다. **실제로 얼마나 드문지는 아직 측정하지 않았다.** 동일하게 50개 단어에 같은 logit penalty를 주어도, 실제로 바뀌는 생성 확률은 크게 다를 수 있다는 것이 검증할 문제다. [S01]

따라서 “특정 의미의 단어를 억제해야 도움이 되는가”와 “선택 확률을 충분히 바꾸는 개입이면 효과가 생기는가”를 분리한다. 원 논문이 틀렸다고 전제하지 않는다.

## 제안 H1

**같은 prefix에서 실질적 확률 변화량을 맞춘 비분기 대조 단어 억제는, 분기 표지 단어 억제와 비교해 평균 잔여 생성 토큰이 ±10%, 최종 정답률이 ±3%p 이내로 동등하다.**

H1은 동등성 가설이다. 유의하지 않은 차이를 동등성으로 해석하지 않는다. 주 후보와 마찬가지로 허용 범위는 확증 전에 확정한다.

## 비교 설계

| 조건 | 역할 |
|---|---|
| 무개입 | 절대 효과 기준 |
| 원문의 분기 표지 단어 억제 | 기존 방법 |
| 원문의 무작위 단어 억제 | 기존 비교의 재현 |
| 비분기 담화 단어 억제 | 문장 내 역할이 비교적 비슷한 대조 |
| 확률·출현 조건을 맞춘 일반 단어 억제 | 개입량을 맞춘 다른 종류의 대조 |

마지막 두 대조군은 개발 자료로만 만든다. 최소 3개 독립 목록을 고정하고 가장 잘 나온 것만 고르지 않는다. 숫자·연산자·EOS·reasoning 종료·정답 형식 토큰은 주 대조 목록에서 제외한다. 비분기 담화 단어도 기능이 완전히 중립적이지 않으므로 단일 목록의 결과만으로 의미를 배제하지 않는다.

## 개입량을 맞추는 방법

전체 softmax에서 대상 단어 집합의 확률 합을 r, penalty를 lambda라 하면 정규화 상수는 `Z=1-r+r*exp(-lambda)`이고, 해당 집합의 새 확률은 `r'=r*exp(-lambda)/Z`다. 원래 분포와 새 분포의 total variation은 `r-r'`다.

이 식은 softmax 재정규화에서 직접 유도된다. 따라서 단어 수와 lambda가 같아도 r이 다르면 개입량이 다르다. 이 수학적 사실 자체를 새 발견으로 주장하지 않는다. **남은 미검증 질문은 이를 통제했을 때 실제 자유 생성의 이득이 남는가**이다.

깨끗한 기전 검사는 top-p=1에서 시작한다. 같은 baseline prefix에서 두 개입의 TV를 맞추되, 맞출 수 있는 목표량·최대 penalty·오차 허용 범위를 개발 자료에서 고정한다. 원문의 top-p=0.95 재현에서는 mask 변화까지 포함한 최종 샘플링 분포의 TV를 기록한다. softmax 단계의 일치만으로 샘플링 뒤에도 같은 개입이라고 주장하지 않는다.

분기 표지 개입이 불가능하거나 대조군이 같은 크기의 개입을 만들 수 없는 prefix에서는 한쪽만 처리하지 않는다. 양쪽 공통으로 제외하는 사전 규칙을 쓰고, 제외율을 보고한다. 주요 prefix의 80% 미만에서 매칭이 성립하면 질문의 범위가 지나치게 좁아질 수 있어 보류한다. 80%는 제안 관문이며 관측 결과가 아니다.

같은 prefix의 fork 실험과 처음부터 끝까지 개입한 자유 생성은 다른 추정량이다. 전자는 국소적 개입 효과, 후자는 실제 정책 효과로 따로 보고한다. prefix는 무개입 생성에서 사전 규칙으로 선택하며 gold answer가 등장하는 위치를 보고 선택하지 않는다.

## 결과와 가치

- H1이 정밀하게 지지되면, 의미별 단어 선택의 필요성을 주장할 때 개입량을 통제해야 한다는 증거가 된다.
- 매칭 뒤에도 분기 표지의 우위가 충분히 크고 여러 대조군에서 재현되면, 단순 확률 변화량만으로 설명할 수 없는 표적 특이성의 근거가 된다. 특정 단어가 인간처럼 ‘망설임’을 수행한다는 증거는 아니다.
- 매칭 불가능, 넓은 구간, 특정 단어 목록만의 효과면 완결된 주가설 결과로 보기 어렵다.

## 1순위가 아닌 이유

어휘 집합의 기능을 완전히 맞추기 어렵고, 매칭 후에도 문법·구문·종료 기능의 잔여 차이가 남는다. H1 미지지 결과가 기존 주장의 강화 정도에 그칠 위험도 있다. 따라서 단순 구현의 매력만 보고 자동으로 백업 성공을 기대하지 않는다. 주 후보가 실패하면 교수님과 이 후보의 독립 기여를 다시 검토해야 한다.
