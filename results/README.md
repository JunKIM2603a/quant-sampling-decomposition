# 실험 결과 상태

2026-09-29 현재 모델 학습·추론 실험을 수행하지 않았습니다.

이 저장소에 있는 수치 중 문헌의 보고값과 계산량 시나리오는 자체 실험 결과가 아닙니다. 가설의 50%/20%/3%p 기준도 관측값이 아닙니다.

승인 후 실행할 실험마다 다음을 구분합니다.

- `development`: 구현·설정 개발
- `pilot`: 원 현상과 실행·검정력 관문 확인
- `confirmatory`: 사전에 동결한 주가설 평가
- `replication`: 별도 데이터·모델·양자화 재현
- `exploratory`: 사후 분석, 주가설 지지 판정에 미사용

첫 실행 전 모델·데이터 revision 및 manifest를 고정합니다.
